# Implement the calculator's expression evaluator

`calc/evaluator.py` is a stub. Implement `evaluate(expr: str) -> float` exactly as specified in
its module docstring (grammar, precedence, errors). Do not use `eval`, `exec`, `compile`, the `ast`
module or any parsing library. `calc/cli.py` already calls it.

Keep the existing tests in `tests/` passing and add more.
